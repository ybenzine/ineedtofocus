| `frontend/public/sounds/chime.wav` | Interval chime (unlimited-timer reminders)                     | 1.1 s, 35 KB  | Synthesised by `frontend/scripts/generate-sounds.mjs` (two soft sine notes)                        | Original work generated by this repository's script; same license as the repository. No third-party material |
| `frontend/public/sounds/bell.wav`  | End bell (automatic phase change, session end, 12 h auto-stop) | 2.2 s, 70 KB  | Synthesised by `frontend/scripts/generate-sounds.mjs` (soft struck tone with inharmonic overtones) | Same as above                                                                                                |

Both are mono, 16 kHz, 16-bit WAV with no voice. To change them, edit the script and run
`node scripts/generate-sounds.mjs` from `frontend/`.

They live in `public/` so the service worker (#19) can precache `sounds/chime.wav` and
`sounds/bell.wav`; the app loads them from `${import.meta.env.BASE_URL}sounds/…`.

## Rain loop (F8, AC8.3)

| File                             | Used for                       | Length / size | Source                                                                                       | License                                                                                                      |
| -------------------------------- | ------------------------------ | ------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `frontend/public/audio/rain.wav` | Background rain (AC8.1, AC8.2) | 30 s, 469 KB  | Synthesised by `frontend/scripts/generate-rain.mjs` (seeded noise hiss plus random droplets) | Original work generated by this repository's script; same license as the repository. No third-party material |

Mono, 8 kHz, 16-bit WAV. It is generated rather than a recorded CC0 file because no CC0 recording
was verifiable for this build; the output is deterministic (fixed seed). The noise filter and the
droplet tails wrap around the end, and the slow swell uses whole cycles, so the last sample flows
into the first and the loop has no seam. A test checks the length, size and the seam.

To change it, edit the script and run `node scripts/generate-rain.mjs` from `frontend/`. It lives
in `public/audio/` so the service worker (#19) precaches it; the app loads it from
`${import.meta.env.BASE_URL}audio/rain.wav` and plays it through a looping Web Audio
`AudioBufferSourceNode`. A recorded CC0 replacement can be dropped in at the same path if one is
found (record its source and license here).
